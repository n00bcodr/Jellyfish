2 Logo

Shown in the top bar. Use your own to brand your server.

Upload an image or paste an address, and the preview updates as soon as you do. Addresses that work: a file in your GitHub repo (the normal github.com/you/repo/blob/main/logo.png link is fine), an ImgBB direct link (https://i.ibb.co/…), an Imgur link, or any other https link straight to a PNG, SVG, WebP or JPEG.
